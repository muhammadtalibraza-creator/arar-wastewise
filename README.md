# ARAR WasteWise — Smart Hospital Waste Management, Staff Training & HSE Competency Platform

A professional, interactive, responsive web application developed by **ARAR Group of Companies / ARAR Innovations (Pvt.) Ltd.** to demonstrate how a digital training and competency platform can improve hospital staff awareness, waste segregation knowledge, safe handling awareness, training completion monitoring, and understanding of the infectious waste management workflow.

> ⚠️ **Demonstration Prototype:** This is a demonstration prototype. All metrics, records and scores shown are fictional. Progress is stored locally in the browser only.

## 🎯 Key Features

- **12 Learning Modules** covering healthcare waste fundamentals, classification, segregation, handling, traceability, storage, treatment, spills, equipment, general waste, regulation and training.
- **Waste Identification Simulator** — interactive classification activity with instant feedback.
- **Scenario-Based Learning** — fictional scenarios for spills, leaks, damaged bags and record mismatches.
- **Pre/Post Training Assessments** — baseline and post-training assessments with topic-wise performance.
- **Training QR Code Centre** — module-specific training URLs and QR code generation.
- **Supervisor Dashboard** — completion rates, average scores and commonly missed topics.
- **Digital Segregation Audit** — ward-level demonstration checklist.
- **Training Certificate Generator** — printable demonstration certificate.
- **Content & SOP Review Centre** — approval status tracking for all operational content.

## 🛠️ Technology Stack

- **HTML5** — semantic markup
- **CSS3** — modern responsive design with dark mode
- **Vanilla JavaScript** — no third-party dependencies
- **LocalStorage** — non-sensitive demo progress storage
- **GitHub Pages** — static hosting
